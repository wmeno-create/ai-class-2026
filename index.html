The problem

Field data needs a path to a report.

CMT field reporting brings together test data, testing standards and procedures, test locations, and field photos. FieldBook explores a workflow that brings these inputs into the report process.

Benefits not yet validated.

How it works

A proposed reporting workflow.

The concept follows the field data from entry through a final project manager review.

01 / INPUT

Enter field information

Compare with standards

Compare the entered test data to CMT testing standards and procedures.

03 / REPORT & REVIEW

Generate and review

Generate a CMT report from the input data, with a project manager review at the end of the tool.
